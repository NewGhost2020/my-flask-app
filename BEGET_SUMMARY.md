## 🛠️ Скрипты (3 файла)

### 1. deploy.sh (5.4 KB) ⭐
🚀 **Автоматический деплой**

**Что делает:**
- Клонирует/обновляет репозиторий
- Создает виртуальное окружение
- Устанавливает зависимости
- Инициализирует базу данных
- Запускает тесты
- Создает .env файл
- Выводит инструкции по следующим шагам

**Использование:**
```bash
bash deploy.sh
```

### 2. bot_control.sh (3.2 KB) ⭐
🎛️ **Управление Telegram ботом**

**Команды:**
- `./bot_control.sh start` - запустить бота
- `./bot_control.sh stop` - остановить бота
- `./bot_control.sh restart` - перезапустить
- `./bot_control.sh status` - проверить статус
- `./bot_control.sh logs` - показать логи
- `./bot_control.sh tail` - логи в реальном времени

**Особенности:**
- Управление PID файлом
- Автоматическая активация venv
- Цветной вывод
- Проверка процессов

### 3. telegram_bot.service (601 B)
⚙️ **Systemd service файл**

**Для чего:**
- Автозапуск бота при перезагрузке сервера
- Автоматический перезапуск при сбоях
- Управление через systemctl (для продвинутых)

**Использование:**
```bash
# Установка (нужны root права)
sudo cp telegram_bot.service /etc/systemd/system/
sudo systemctl enable telegram_bot
sudo systemctl start telegram_bot
```

## 🚀 Быстрый старт (TL;DR)

```bash
# 1. Подключитесь
ssh ваш_логин@ваш_логин.beget.tech

# 2. Деплой
mkdir -p ~/projects && cd ~/projects
git clone https://github.com/NewGhost2020/my-flask-app.git promo-parser
cd promo-parser
git checkout feat/promo-parser-bigdabach-sqlalchemy
bash deploy.sh

# 3. Настройте
nano .env  # добавьте BOT_TOKEN
nano telegram_bot.py  # код из BEGET_QUICKSTART.md

# 4. Установите библиотеки
source venv/bin/activate
pip install python-telegram-bot python-dotenv

# 5. Запустите
./bot_control.sh start

# 6. Проверьте в Telegram
# Отправьте /start вашему боту
```
