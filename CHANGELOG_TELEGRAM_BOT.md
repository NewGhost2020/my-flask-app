## 🔐 Безопасность

### Рекомендации
1. Не публикуйте токен бота в Git
2. Используйте переменные окружения:
   ```python
   BOT_TOKEN = os.getenv('TELEGRAM_BOT_TOKEN')
   ```
3. Ограничьте доступ по User ID:
   ```python
   ALLOWED_USERS = [123456789, 987654321]
   ```

## 🐛 Известные ограничения

1. **Токен в коде** - нужно заменить вручную
2. **Polling режим** - для production лучше webhook
3. **Нет персистентного хранилища FSM** - используется MemoryStorage
4. **Один экземпляр** - нет поддержки нескольких пользователей одновременно
